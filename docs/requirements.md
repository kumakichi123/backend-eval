# AIモデル着用画像生成SaaS 要件定義（ドラフト）

## 1. 目的 / ゴール
- 平置きのトップス画像（表/裏）から、AIモデルが着用した商品画像（表/裏）を生成する。 
- EC運営代行・アパレル商社など、商品撮影の外部化/省力化ニーズがある事業者向けに提供する。 
- 料金は **月額＋従量課金** で、月額を抑えて差別化する。 
- 成功指標は **月間処理枚数** を中心に評価する。 

## 2. 対象ユーザー / 想定利用規模
- 主な利用者: 商品を販売する事業者（EC運営代行・アパレル商社・ブランド運営チーム等）。 
- 1社あたりの月間処理枚数: 100枚程度を想定。 

## 3. 入力要件
- 対象カテゴリ: **トップスのみ（初期フェーズ）**。 
- 画像種別: **平置き画像の表/裏**。 
- 入力単位: **1 SKU = 1商品×1色**。サイズ違いは原則同一としてカウント。 
- 入力方法: **一括処理**が基本。
  - フォルダ/CSV投入 → まとめて処理 → まとめて返却。 

## 4. 出力要件
- 出力形式: **白背景の商品ページにそのまま使える画像（表/裏）**。 
- サイズ指定: 原則 **相似で統一**（厳密なサイズ固定は不要）。 
- 品質要件: 商品ページ掲載に耐える自然さ・破綻の少なさ。 

## 5. モデル / スタイル要件
- 既定モデルを複数用意し、利用者が選択可能にする。 
- 体形・身長などのカスタマイズは **要望あり**（難易度は高い可能性）。
- ブランド世界観/トーンの指定は **不要**。 

## 6. 再生成・課金ルール（揉めない設計）
- 生成は **1回で確定しない**前提。
- ルール方針:
  - **「1 SKUあたり○枚まで再生成込み」** の上限設定。 
  - **破綻判定でNGになった回は課金しない**。 
  - 破綻判定の基準と運用（自動/手動/ハイブリッド）を明文化する。 

## 7. UI / UX 要件
- **Web管理画面のみ**（APIは不要）。 
- **直感的でシンプル**なUI。 
  - 可能な限り **文字ではなく視覚（アイコン/サムネイル）中心**。 
  - シンプルな導線: 「投入 → 進行確認 → 結果ダウンロード」。 

## 8. 非機能要件（未確定）
- 性能/速度要件: 未定。 
- セキュリティ/保管期間: 未定。 
- SLA/サポート: 必要だが未定。 

## 9. 今後の検討事項
- 破綻判定の定義と実装方式。 
- 体形/身長カスタマイズの技術的実現性。 
- 画像品質の自動評価/再生成フロー。 
- 月額＋従量の料金テーブル（SKU・再生成回数の組み込み方）。 
- 公開運用（クラウド公開/外部アクセス）の設計。
